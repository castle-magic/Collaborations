# YouTube Clone — Student of Junior

YouTube'ning sodda front-end nusxasi. Loyiha YouTube interfeysidagi asosiy bo'limlar va video kartochkalarni namoyish etadi. Hozircha "Moda" (fashion) mavzusidagi namunaviy videolar bilan to'ldirilgan.

🔗 **Jonli demo:** [studentofjunior.netlify.app](https://studentofjunior.netlify.app/)

## Imkoniyatlar

- Qidiruv paneli (Search)
- Yon menyu: Home, Library, Subscriptions, History
- Video kartochkalar: rasm, sarlavha, kategoriya, ko'rishlar soni va yuklangan vaqt
- Netlify orqali joylashtirilgan (deploy)

## Lokal ishga tushirish

1. Repozitoriyni yuklab oling:
   ```bash
   git clone https://github.com/<foydalanuvchi-nomi>/<repozitoriy-nomi>.git
   ```
2. Papkaga kiring:
   ```bash
   cd <repozitoriy-nomi>
   ```
3. `index.html` faylini brauzerda oching yoki VS Code'dagi **Live Server** kengaytmasidan foydalaning.

## Netlify'ga joylashtirish

1. Loyihani GitHub'ga yuklang.
2. [Netlify](https://www.netlify.com/)'da **Add new site → Import an existing project** ni tanlang.
3. Repozitoriyni ulang va deploy qiling. Build buyrug'i kerak emas, publish papkasi — loyiha ildizi (`/`).
